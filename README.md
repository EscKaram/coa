# Системно-ориентированная архитектура — домашние задания

Репозиторий с домашними заданиями по курсу «Системно-ориентированная архитектура» (ВШЭ).

Каждое задание лежит в отдельной ветке. В `main` только этот файл.

| ДЗ | Ветка | Тема |
|---|---|---|
| 1 | [`hw1`](../../tree/hw1) | Архитектура маркетплейса: C4 Container диаграмма, домены, владение данными, каркас `catalog-service` |
| 2 | [`hw2`](../../tree/hw2) | Marketplace: OpenAPI + CRUD, кодогенерация, PostgreSQL + Flyway, бизнес-логика заказов, JWT, роли |

Инструкция по запуску находится в `README.md` соответствующей ветки.

```bash
git checkout hw2
```
